# 전시 체크리스트

졸업전시 당일 PURE 앱을 돌리기 위한 것. 설계서 STEP 25 의 체크리스트를 실제
구현에 맞춰 옮겼다.

---

## 전시 전날 — 맥에서

```bash
./scripts/install_device.sh
```

릴리스 빌드를 만들어 연결된 아이폰에 설치한다. 키는 `.env.local` 에서 읽는다.

> **⚠ 이 단계를 건너뛰면 안 된다.**
> 무료 Apple ID 로 서명하므로 프로비저닝 프로파일이 **7일**짜리다. 기간이 지나면
> 앱이 아예 켜지지 않는다. 전시가 여러 날이면 유료 개발자 계정(연 $99)으로
> 올려서 1년짜리 프로파일을 받는 쪽이 안전하다.

설치 직후 기기에서 한 번:
**설정 → 일반 → VPN 및 기기 관리 → 개발자 앱 → 신뢰**

맥은 전시장에 가져간다. 앱이 죽으면 다시 깔 길이 그것뿐이다.

## 기기 설정

- [ ] 자동 잠금 **안 함** (앱이 wakelock 을 켜지만 설정도 같이 꺼 둔다)
- [ ] 저전력 모드 **끄기** — 켜져 있으면 WebGL 이 느려져 시뮬레이터가 버벅인다
- [ ] 밝기 고정 (자동 밝기 끄기)
- [ ] 방해금지 켜기

- [ ] 테스트 영상 3개를 사진 앱에 미리 저장 (고양이 포함)

## 전시 중 쓰는 숨은 기능

| 할 일 | 방법 |
|---|---|
| 데모 모드 켜기/끄기 | 사이드바 → 로봇 상태 줄("Purebot / Connected") **5번 탭** |
| 데모 모드 끄기 (켜져 있을 때) | 홈 상단 검정 배너의 `Turn off` |
| 관람객 사이 초기화 | 마이 → Version **5번 탭** → Reset demo data |

초기화하면 첫 실행 플래그도 지워져서 다음 관람객에게 05 모션 시그니처부터
보여 줄 수 있다.

## 시연 대본

1. 홈에서 칩 하나 ("I'm so tired…")
2. 되묻는 질문 둘에 답 → 로봇이 움직이는 답장
3. `Save` → 상황과 재생 방식 고르기
4. 사이드바 → Library → 저장된 모션 재생
5. Robot → 모션 시그니처 바꾸기 → 대기 모션이 달라지는 것
6. 영상 첨부 (고양이) → 같은 흐름

## 뭔가 이상할 때

| 증상 | 손볼 곳 |
|---|---|
| 앱이 안 켜진다 | 프로파일 만료. 맥에서 `./scripts/install_device.sh` 다시 |
| 로봇이 안 보인다 | 시뮬레이터 wasm. 앱을 완전히 끄고 다시 켠다 (스플래시 동안 올린다) |
| 생성이 안 온다 | 데모 모드를 켜 버린다 (사이드바 5번 탭). 시연은 그대로 돈다 |
| 브리지가 의심스럽다 | `./scripts/dev.sh selftest` 로 15건 자체검사 |
| 화면 하나만 보고 싶다 | `./scripts/dev.sh install --dart-define=START_ROUTE=/library` |
